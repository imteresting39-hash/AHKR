IMP2 Arrow Helper 사용법
========================

1. 준비
--------
- Windows PC에서 사용합니다.
- Python 3.x가 설치되어 있어야 합니다.
-바탕화면에서 디스플레이 설정-해상도가 1920*1080이어야 합니다.

2. 처음 한 번만 설치
--------------------
같은 폴더에 있는 install.bat를 더블클릭하세요.

install.bat가 이 프로그램에 필요한 Python 라이브러리를 한 번에 설치합니다.

설치되는 라이브러리:
- OpenCV (opencv-python)
- NumPy (numpy)

3. 실행
--------
설치가 끝난 뒤 아래 Python 파일을 실행하세요.

IMP2_Arrow_Helper.py

더블클릭으로 실행되지 않는 경우 명령 프롬프트에서 다음처럼 실행할 수 있습니다.

python IMP2_Arrow_Helper.py

4. 프로그램 기능
-----------------
- IMP2 회피 화살표를 화면에서 감지합니다.
- 같은 방향으로 표시되는 3개의 화살표를 1회의 회피 입력으로 처리합니다.
- 한 회피당 해당 방향키를 1번만 입력합니다.
- F8 : 프로그램 ON/OFF
- F9 : 프로그램 종료
- Alt+Tab으로 다른 창을 갔다가 워크래프트로 돌아오면 감지 상태를 다시 초기화합니다.

5. 주의
--------
- 워크래프트가 활성 창일 때만 입력합니다.
- 화면 해상도/게임 UI 배치가 크게 달라지면 감지 위치를 조정해야 할 수 있습니다.
- install.bat는 처음 한 번만 실행하면 됩니다. 이미 라이브러리가 설치되어 있다면 다시 실행할 필요가 없습니다.
